# 🛍️ Shopify Store

A modern e-commerce web application inspired by Shopify, built with React and TypeScript. The application enables users to browse products, search items, filter collections, manage their cart, and enjoy a seamless shopping experience across devices.

## 🚀 Features

- Product listing and browsing
- Advanced product search
- Category-based filtering
- Product detail pages
- Shopping cart management
- Responsive design for all screen sizes
- Smooth UI interactions and animations
- Optimized component rendering
- Clean and intuitive user experience

## 🛠️ Tech Stack

### Frontend
- React.js
- TypeScript
- Tailwind CSS
- REST APIs
- Redux Toolkit
